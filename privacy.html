Política de Privacidade

Vigência: 23 de agosto de 2026

Visão geral

O CortaFé Studio é executado localmente. Vídeos, transcrições, projetos e configurações permanecem no computador do usuário, salvo quando ele solicita uma operação em serviço externo.

Dados tratados

Para conectar redes sociais, tratamos identificadores básicos da conta, nome exibido, tokens OAuth, opções de publicação e histórico operacional. Para publicar, enviamos o vídeo, título, legenda, privacidade e configurações escolhidas à plataforma correspondente.

Finalidades

Os dados são usados somente para autenticar a conta, mostrar ao usuário qual conta está conectada, renovar autorizações, enviar publicações solicitadas e informar o resultado do processamento.

Armazenamento e segurança

Credenciais e tokens são protegidos localmente por mecanismos de proteção de dados do sistema. Não vendemos dados pessoais nem usamos dados do TikTok para publicidade ou criação de perfis.

Compartilhamento

Dados são compartilhados com TikTok, YouTube ou outra plataforma apenas quando necessário para uma ação solicitada. O tratamento posterior segue a política da respectiva plataforma.

Retenção e exclusão

Os dados ficam no computador até que o usuário desconecte a conta, exclua o projeto ou remova o armazenamento local. O acesso também pode ser revogado nas configurações da plataforma.

Direitos e contato

Para dúvidas, acesso ou exclusão, escreva para alessonbarauna1@gmail.com.

Alterações

Esta política poderá ser atualizada para refletir mudanças do aplicativo ou requisitos legais. A data de vigência será atualizada nesta página.
